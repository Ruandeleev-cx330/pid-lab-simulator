# 物理模型与假设

所有模型都是固定步长（Δt = 0.01 s）离散积分，控制器每 10 ms 更新一次。
数值积分使用经典四阶 Runge–Kutta；直流电机因电气时间常数小于控制周期而内部子步 8 次
（子步只影响积分精度，不改变仿真时钟）。

---

## 1. 温度控制（一阶热模型）

```
C·dT/dt = P_h − K_loss·(T − T_amb) + Q_d
```

| 参数 | 值 | 单位 |
| --- | --- | --- |
| C 热容 | 120 | J/K |
| K_loss 热损系数 | 12 | W/K |
| T_amb 环境温度 | 20 | °C |
| P_h 加热功率 | 0 – 1200 | W |
| 时间常数 τ = C/K_loss | 10 | s |
| 安全范围 | −5 – 160 | °C |

- 加热器单向（0 W 起步），因此天然存在“只能加热、不能主动制冷”的非对称饱和；
- 冷负载扰动 Q_d 直接进入能量方程，负值代表额外散热；
- 满载稳态温度 20 + 1200/12 = 120 °C，与目标区间上限 110 °C 匹配。

**假设**：集总热容模型，内部温度均匀，忽略辐射非线性。

---

## 2. 直流电机（二阶：电枢 + 机械）

```
J·dω/dt = Kt·i − b·ω − τ_L
L·di/dt = V − R·i − Ke·ω
dθ/dt   = ω            （转子角，仅用于动画）
```

| 参数 | 值 | 单位 |
| --- | --- | --- |
| J 转动惯量 | 6.0e-4 | kg·m² |
| b 黏性摩擦 | 2.0e-5 | N·m·s/rad |
| Kt 转矩常数 | 0.05 | N·m/A |
| Ke 反电动势常数 | 0.05 | V·s/rad |
| R 电枢电阻 | 1.5 | Ω |
| L 电枢电感 | 0.008 | H |
| 电压指令 | 0 – 24 | V |
| 电气时间常数 L/R | 5.3 | ms |
| 机械时间常数 | ≈0.36 | s |
| 空载最高转速（24 V） | ≈474 | rad/s |

- **子步**：L/R = 5.3 ms < 10 ms 控制周期，RK4 在 λ·h = −1.9 处仍稳定但精度不足，
  因此每个控制周期内部再分 8 步（h = 1.25 ms），既保持 10 ms 控制周期不变，又避免数值失真；
- 负载转矩 τ_L 作为扰动直接进入机械方程，稳态转速下降 (τ_L·R)/(Kt·Ke + b·R)；
- 安全包络：|ω| > 700 rad/s（超速）或 |i| > 30 A（过流）。

**假设**：他励直流电机，磁路不饱和，忽略电刷压降与温升对 R 的影响。

---

## 3. 液位控制（质量守恒 + 重力出流）

```
A·dh/dt = q_in − k_o·√(max(h,0)) − q_leak
```

| 参数 | 值 | 单位 |
| --- | --- | --- |
| A 截面积 | 0.08 | m² |
| k_o 出流系数 | 0.02 | m^1.5/s |
| q_in 泵流量 | 0 – 0.05 | m³/s |
| 罐高 | 1.5 | m |
| 安全下限 | 0.02 | m |
| h = 1 m 处时间常数 | ≈8 | s |

- `project()` 把液位钳制在 [0, 1.8]：空罐不会出现负液位，且 h=0 时出流严格为 0；
- 非线性（√h）使回路增益随液位变化——这正是需要现场调参的原因；
- 安全包络：h ≥ 1.5 m 溢出，h ≤ 0.02 m 抽空。

## 4. 二轮平衡小车（倒立摆缩比模型）

状态：车身倾角 θ、角速度 ω、车轮角 φ、轮速 ω_w、位移 x。

```
J_b·dω/dt   = m·g·l·sin θ − b·ω + u + τ_ext
J_w·dω_w/dt = −u − b_w·ω_w
dφ/dt = ω_w ,  dx/dt = r·ω_w
```

| 参数 | 值 | 单位 |
| --- | --- | --- |
| m 车身质量 | 1.5 | kg |
| l 质心高度 | 0.35 | m |
| J_b 车身转动惯量 | 0.35 | kg·m² |
| b 阻尼 | 0.05 | N·m·s/rad |
| J_w 车轮等效惯量 | 0.02 | kg·m² |
| b_w 车轮阻尼 | 0.05 | N·m·s/rad |
| r 轮半径 | 0.075 | m |
| 控制量 u | ±8 | N·m |
| 倾倒角 | 40° (0.7 rad) | — |

### 控制量符号约定（重要）

`u` 定义为**驱动系统作用在车身上的反作用力矩**，即 `u = −τ_wheel`。
对 θ > 0（向前倾），控制器输出 u < 0，车轴获得正向力矩、车轮向倾倒方向加速，
车身得到反向力矩而被拉回——这与真实平衡车的物理过程一致。

由此得到线性化形式：`θ̈ ≈ −(57.3·Kp − m·g·l)/J_b · θ − (57.3·Kd + b)/J_b · θ̇`
（角度以度为单位测量），因此 **Kp 必须大于 m·g·l ≈ 0.09 N·m/°** 才能站住，
这正是本项目“比例不足必然倒”的教学点。

**假设**：忽略车轮-地面滑移、忽略电机电流环、车身简化为单一刚体；前进位移由滚动无滑移
运动学推导（`dx/dt = r·ω_w`），用于动画地面滚动，不参与控制。

## 5. 倒立摆（非线性小车-摆杆）

状态：小车位置 x、速度 ẋ、摆角 θ、角速度 θ̇。

```
(M+m)·ẍ + m·l·cos θ·θ̈ − m·l·sin θ·θ̇² = F − b_c·ẋ
m·l·cos θ·ẍ + m·l²·θ̈ − m·g·l·sin θ     = −b_p·θ̇
```

解析求解（`den = l·(M + m·sin²θ)`）：

```
θ̈ = [(M+m)·g·sin θ − (F/l)·cos θ − m·cos θ·sin θ·θ̇²] / den
ẍ = [F − b_c·ẋ + m·l·sin θ·θ̇² − m·g·sin θ·cos θ + b_p·θ̇·cos θ/l] / (M + m·sin²θ)
```

| 参数 | 值 | 单位 |
| --- | --- | --- |
| M 小车质量 | 0.5 | kg |
| m 摆球质量 | 0.2 | kg |
| l 摆长 | 0.6 | m |
| b_c 小车摩擦 | 0.1 | N·s/m |
| b_p 转轴阻尼 | 0.002 | N·m·s/rad |
| 驱动力 | ±15 | N |
| 轨道 | ±2.4 | m |
| 倒下角 | 34° (0.6 rad) | — |

### 驱动极性

`F = −u`（`PENDULUM_DRIVE_POLARITY = −1`）：正控制指令使小车向 −x 加速。
角度以 +x 方向倾倒为正，于是正角度误差 → 负指令 → 小车向倾倒方向加速 → 摆杆被顶回，
与“把支点移到落体下方”的物理直觉一致。该极性由 `tests/physics/inverted-pendulum.test.ts`
的“driving the cart under the lean reduces the angle”用例验证。

**假设**：摆杆为端点集中质量（无自身转动惯量），忽略轨道摩擦非线性，小车与摆杆为平面运动。
本实验是**单回路角度 PID**：不控制小车位置，因此长时间运行会出现位置漂移，轨道越界即判失败。

## 6. 数值与稳定性

- `tests/unit/integrator.test.ts` 验证 RK4 对 dy/dt = −y 的误差、步长减半时约 16 倍收敛、
  Euler 与 RK4 的精度差异、子步不改变仿真时钟、投影保持物理有效；
- `tests/physics/*.test.ts` 用解析解/守恒关系校验每个模型（热时间常数、电机稳态转速、
  液位平衡点、倒立摆线性化增长率 cosh(λt) 等）；
- 所有状态每步做 `Number.isFinite` 检查，出现 NaN/Infinity 立即冻结并给出故障原因；
- 执行器指令在 PID 输出端与模型入口双重钳制。
